# VPaperPad
VPaperPad is a lightweight text editor written in Vbscript, built mainly to demonstrate the power of Vbscript when coupled with COM objects to create some very nice graphics like shown in this application. It currently features a minimal feature set, but many features are planned.

# Installing
Here are the steps to install VPaperPad.

1) Get the zip file of the repository.

2) From the repository folder go inside the "dependencies" folder.

3) Run "install dependencies.bat" as administrator.

4) Return back to the repository folder and go inside the "src" folder.

5) Run "launch.bat" and enjoy using VPaperPad!

# Uninstalling

1) From the repository folder go inside the "dependencies" folder.

2) Run "uninstall dependencies.bat" as administrator.

3) Delete the repository folder.
